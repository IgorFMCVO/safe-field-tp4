# TP3 — controle sequencial e integração lógica

Origem recuperada: `igor_monteiro_PB_TP3(1).zip`.
Conteúdo no ZIP institucional: `assembly_tp3`, `verilog_tp3`, Makefiles, parser/jump table, GPIO simulado, FSM, diagramas, relatórios, logs e screenshots.

A etapa foi verificada por QEMU, GTKWave e síntese/place-and-route Gowin; o relatório registra que as placas ainda não estavam fisicamente disponíveis. O frame paralelo lógico de oito bits é histórico e difere dos quadros UART do TP5 final.

Este diretório é um índice. Os arquivos históricos selecionados estão em `historico_tps/TP3` dentro de `Igor_Monteiro_PB.ZIP`.
