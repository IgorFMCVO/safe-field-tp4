# Demonstração TP5 — ordem de abertura

Execute `ABRIR_DEMO_TP5.ps1`. O script abre somente documentos e evidências;
não programa a FPGA e não executa testes.

1. Arquitetura final.
2. RTL crítico: top, Q1.15 e FP16.
3. Log dos cinco testes e waveform VCD de coexistência.
4. Assembly ARM64 e log de execução nativa.
5. Resultados físicos bidirecionais e desempenho.
6. Evidência acústica preservada.
7. Relatório PDF e resultados finais.

Gravação/webcam e publicação do link são ações do operador.
