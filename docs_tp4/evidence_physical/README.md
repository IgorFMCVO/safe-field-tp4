# Evidências físicas selecionadas

Esta pasta reúne as capturas numéricas, gráficos e logs que sustentam o
relatório acadêmico. Os arquivos são copiados das evidências imutáveis já
existentes; não são novas medições nem simulações apresentadas como físicas.

- `audio/`: silêncio, voz, palmas, comparação e estabilidade;
- `mvp_hw_bridge/`: validação física Tang -> Raspberry;
- `PHYSICAL_DIAGNOSTIC_LOG.md`: cronologia de diagnóstico da aquisição.

Não havia fotografia estática do hardware no workspace. O roteiro de vídeo
indica exatamente a tomada ao vivo que deve mostrar aluno, montagem e sinais.
